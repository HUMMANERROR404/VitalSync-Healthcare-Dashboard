## 📌 Project Overview
In most healthcare settings, patient data is kept in separate silos. Clinical measurements (blood pressure, blood glucose, ECG) are tracked independently from daily lifestyle habits (stress, sleep patterns, physical activity). **VitalSync** bridges this gap by unifying clinical and behavioral data into an interactive Power BI dashboard for early stroke and heart disease risk prediction.

## 🛠️ Tools & Technologies
* **Data Extraction & Transformation (ETL):** Microsoft Excel (Power Query)
* **Data Modeling & Analytics:** Microsoft Power BI (DAX, Star Schema)
* **Documentation & Version Control:** Microsoft Word, GitHub
