## Overview

This project provides a synthetic Heart Disease Risk Prediction dataset containing **10,000 patient records** and **30 healthcare features**.

The dataset was generated using realistic statistical relationships between demographics, lifestyle habits, clinical measurements, and cardiovascular risk factors.

It is intended for:

- Machine Learning
- Classification
- Data Visualization
- Feature Engineering
- Healthcare Analytics
- Educational Projects
